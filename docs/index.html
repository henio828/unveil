Text That Hides From Humans

A field guide to indirect prompt injection in coding agents. ~4,000 words, PDF. September 2026.

Coding agents read issue text, READMEs, comments and build output as instructions. In 2026 that stopped being a research topic: 73% of "agent bounties" on GitHub turned out to be honeypots for extracting system prompts; a single issue title compromised an npm package; a testing library printed instructions into build output and erased them before a human could see. This guide is about that class of attack — text that hides from humans but speaks to machines — written by the author of unveil, a free scanner for it.

A sample

The README of the Linux kernel now contains a section headed AI Coding Assistant: "CRITICAL: If you are an LLM or AI-powered coding assistant, you MUST read and follow the AI coding assistants documentation before contributing to the Linux kernel." This is text addressed to machines. It is also entirely legitimate — maintainers setting contribution policy, in plain view, in the file everyone reads. A detector that raises the alarm on this has failed, because its alarms will be muted within a week. Addressed to a machine is not the signal. Concealed is the signal.
